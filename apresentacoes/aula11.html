Os 3 tipos de erros

Nem todos são iguais — cada um exige uma solução diferente

🔴 SyntaxError Python não consegue sequer ler o código.

if x = 5: → erro imediato

Detetado antes de correr. Corrige-se no editor.
🟡 RuntimeError O código é válido mas falha durante a execução.

int("abc") → ValueError
1/0 → ZeroDivisionError

É aqui que o try/except atua.
🔵 Erro Lógico O programa corre sem erros mas dá resultados errados.

Calcular média a dividir por N em vez de len(lista)

Só o debugging (e os testes) o detetam.
💡 try/except trata RuntimeErrors. SyntaxErrors impedem o programa de correr. Erros lógicos exigem testes e debugging.

try / except — a estrutura base

Envolver o código perigoso e reagir ao erro

❌ Sem tratamento

nivel = int(input("Nível do agente: "))
# Se o utilizador escrever "cinco":
# ValueError: invalid literal for int()
# → programa crasha!

✅ Com try/except

try:
    nivel = int(input("Nível do agente: "))
    print(f"Nível {nivel} registado.")
except ValueError:
    print("❌ Introduz um número entre 1 e 5.")
💡 O código dentro do try é o que pode falhar. O except só corre se ocorrer o erro especificado — nunca os dois ao mesmo tempo.

Exceções específicas

Captura o erro certo — não uses a rede demasiado larga

import json

def carregar_agentes(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"❌ Ficheiro '{path}' não encontrado.")
        return []
    except json.JSONDecodeError:
        print("❌ Ficheiro corrompido — JSON inválido.")
        return []
    except PermissionError:
        print("❌ Sem permissão para ler o ficheiro.")
        return []
    except Exception as e:
        print(f"❌ Erro inesperado: {e}")
        return []
Exceções mais comuns ValueError · TypeError · FileNotFoundError
ZeroDivisionError · IndexError · KeyError
PermissionError · json.JSONDecodeError
sqlite3.IntegrityError · sqlite3.OperationalError
❌ Nunca fazer isto except: — captura TUDO (até Ctrl+C)
except Exception: pass — silencia o erro

Esconde bugs e torna o debugging impossível.

else e finally

Controlo total sobre o fluxo de erros

try:
    nivel = int(input("Nível (1-5): "))
except ValueError:
    print("❌ Número inválido.")
else:
    # corre SÓ SE não houve exceção
    print(f"✅ Nível {nivel} aceite.")
finally:
    # corre SEMPRE — com ou sem erro
    print("─── fim da operação ───")
try Código que pode falhar. Se falhar, salta imediatamente para o except.
except Só corre se ocorreu o erro especificado. Pode haver vários except.
else / finally else → sem erro.
finally → sempre (fechar ficheiros, DB, etc.)

raise — lançar exceções

Validar dados e comunicar erros com precisão

Validar com raise

def definir_nivel(n):
    if not isinstance(n, int):
        raise TypeError("Nível deve ser inteiro")
    if n < 1 or n > 5:
        raise ValueError(f"Nível {n} inválido (1-5)")
    return n

try:
    definir_nivel(7)
except ValueError as e:
    print(f"❌ {e}")

re-raise — propagar o erro

def guardar_agente(codename, nivel):
    try:
        definir_nivel(nivel)
        # ... guardar na DB ...
    except ValueError:
        print("❌ Nível inválido — agente não guardado")
        raise   # propaga o erro para cima
💡 raise sem argumentos dentro de um except re-lança a mesma exceção — útil para logging antes de propagar.

try / except com SQLite

Tratar duplicados e erros de base de dados sem crashes

import sqlite3

def adicionar_agente(codename, nivel):
    if not 1 <= nivel <= 5:
        raise ValueError(f"Nível {nivel} inválido (1-5)")
    try:
        with sqlite3.connect("agentes.db") as conn:
            conn.execute(
                "INSERT INTO agentes(codename,nivel,ativo) VALUES(?,?,1)",
                (codename, nivel))
        print(f"✅ Agente {codename} adicionado.")
        return True
    except sqlite3.IntegrityError:
        print(f"❌ Codename '{codename}' já existe.")
        return False
    except sqlite3.OperationalError as e:
        print(f"❌ Erro na base de dados: {e}")
        return False
💡 IntegrityError → viola UNIQUE ou NOT NULL. OperationalError → tabela não existe, disco cheio, etc. O with sqlite3.connect() faz rollback automaticamente se houver exceção.

Boas práticas

O que separa código frágil de código robusto

❌ Evitar✅ Fazer
except: — captura tudo, inclusive Ctrl+C Capturar exceções específicas: except ValueError:
except Exception: pass — silencia o erro Sempre dar feedback: print(f"❌ {e}")
try/except em torno de 50 linhas Blocos try pequenos — só o que pode falhar
Mostrar stack trace ao utilizador Mensagem simples para o utilizador, log técnico para o programador
Deixar o programa crasha em produção Valores de retorno seguros (return [], return None)
💡 Regra de ouro: o utilizador vê uma mensagem amigável. O programador vê o erro real (no log ou no terminal de desenvolvimento).

Debugging no PyCharm

Encontrar erros lógicos com breakpoints

🔴 Breakpoints Clica na margem esquerda ao lado do número da linha → ponto vermelho.
O programa para nessa linha e podes inspecionar as variáveis.
⌨️ Atalhos essenciais F7 — Step Into (entra na função)
F8 — Step Over (próxima linha)
F9 — Resume (continua até próximo breakpoint)
Shift+F9 — Correr em modo Debug
🔍 Variables panel No painel "Variables" vês o valor de todas as variáveis no momento em que o programa parou. Passa o rato numa variável no editor para ver o valor inline.
⚡ Evaluate Expression Alt+F8 — abre uma consola onde podes correr código Python no contexto actual.
Ex: testar len(agentes) ou agentes[0] sem alterar o código.

Simulador v4.0 — Arquitetura Robusta

try/except em cada camada — zero crashes

import sqlite3, json

DB = "dados/aula11/agentes.db"

def pedir_nivel():
    """Pede o nível ao utilizador com validação robusta."""
    while True:
        try:
            n = int(input("Nível (1-5): "))
            if not 1 <= n <= 5:
                raise ValueError
            return n
        except ValueError:
            print("❌ Introduz um número entre 1 e 5.")

def adicionar(codename, nivel):
    """Adiciona agente com tratamento de duplicados."""
    try:
        with sqlite3.connect(DB) as conn:
            conn.execute(
                "INSERT INTO agentes(codename,nivel,ativo) VALUES(?,?,1)",
                (codename.upper(), nivel))
        print(f"✅ {codename.upper()} adicionado.")
    except sqlite3.IntegrityError:
        print(f"❌ Codename '{codename.upper()}' já existe.")

def main():
    while True:
        op = input("\n[1] Adicionar  [0] Sair: ").strip()
        if op == "0": break
        if op == "1":
            cod = input("Codename: ").strip()
            niv = pedir_nivel()
            adicionar(cod, niv)
