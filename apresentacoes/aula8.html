Dados que Persistem

Ficheiros de texto · Logs · CSV

O problema: memória que desaparece

Tudo o que está numa variável morre quando o programa fecha

# O Simulador tem uma lista de agentes
agentes = ["Ana", "Bruno", "Carla"]

# O utilizador adiciona um novo agente...
agentes.append("Diana")

# ... e fecha o PyCharm.

# Amanhã, ao abrir de novo:
agentes = ["Ana", "Bruno", "Carla"]
#                           ↑ Diana desapareceu!
  • Variáveis existem apenas em memória RAM — volátil
  • Para dados sobreviverem ao programa precisamos de ficheiros

open() — a porta de entrada

Três modos essenciais — escolhe o certo para cada situação

ModoSignificadoFicheiro existe?Apaga conteúdo?
'r'Ler (read)Tem de existirNão
'w'Escrever (write)Cria se não existir✅ Sim
'a'Acrescentar (append)Cria se não existirNão
⚠️ Modo 'w' apaga todo o conteúdo anterior sem aviso — usa com cuidado.

with...as — a forma certa

Garante que o ficheiro fecha sempre, mesmo se houver erro

❌ Forma arriscada: 
f = open('dados.txt', 'r')
conteudo = f.read()
# Se houver erro aqui...
f.close()   # nunca chega aqui!
✅ Forma correta: 
with open('dados.txt', 'r') as f:
    conteudo = f.read()
# fecha automaticamente —
# mesmo se houver erro
  • with é um gestor de contexto — abre e fecha automaticamente
  • Sempre que usares open(), usa-o dentro de with

Ler um ficheiro — três formas

Escolhe conforme o que precisas

with open('agentes.txt', 'r', encoding='utf-8') as f:

    # Tudo de uma vez (string)
    tudo = f.read()

    # Linha a linha (lista de strings)
    linhas = f.readlines()

    # Percorrer linha por linha (eficiente para ficheiros grandes)
    for linha in f:
        print(linha.strip())   # .strip() remove o '\n' do fim
read() → string com tudo
readlines() → lista de strings
for linha in f → processa linha a linha

Escrever e acrescentar

write() para um valor, writelines() para uma lista

Criar/substituir (modo 'w'): 
agentes = ["Ana\n", "Bruno\n", "Carla\n"]

with open('agentes.txt', 'w', encoding='utf-8') as f:
    f.writelines(agentes)
    # ou: f.write("Ana\nBruno\n")
Acrescentar log (modo 'a'): 
from datetime import datetime

evento = f"{datetime.now()} login OK\n"

with open('log.txt', 'a', encoding='utf-8') as f:
    f.write(evento)
# cada chamada acrescenta uma linha

💡 Inclui sempre encoding='utf-8' para acentos funcionarem.

Fluxo de um ficheiro

Abrir → operar → fechar (o with faz isso por ti)

✅ Mesmo com erro no meio, o ficheiro fecha sempre — é garantido.

CSV — Comma Separated Values

A forma mais simples de guardar dados em tabela

O que parece no ficheiro: 
nome,nivel,ativo
Ana,ANALISTA,True
Bruno,CADETE,True
Carla,RECRUTA,False
O que representa:
nomenivelativo
AnaANALISTATrue
BrunoCADETETrue
CarlaRECRUTAFalse
  • Primeira linha = cabeçalho (nomes das colunas)
  • Abre em Excel, Google Sheets, LibreOffice — e no Python
  • Ideal para listas de dados simples sem relações complexas

csv.reader e csv.writer

O módulo csv trata das vírgulas e das aspas por ti

Ler: 
import csv

with open('agentes.csv', 'r', encoding='utf-8') as f:
    leitor = csv.reader(f)
    next(leitor)        # saltar cabeçalho
    for linha in leitor:
        print(linha)
# ['Ana', 'ANALISTA', 'True']
Escrever: 
import csv

agentes = [
    ['nome', 'nivel', 'ativo'],
    ['Ana', 'ANALISTA', 'True'],
    ['Bruno', 'CADETE', 'True'],
]

with open('agentes.csv', 'w', newline='', encoding='utf-8') as f:
    escritor = csv.writer(f)
    escritor.writerows(agentes)

DictReader e DictWriter

Aceder às colunas pelo nome — muito mais legível

DictReader — ler como dicionário: 
import csv

with open('agentes.csv', 'r', encoding='utf-8') as f:
    leitor = csv.DictReader(f)
    for agente in leitor:
        print(agente['nome'], agente['nivel'])
        # Ana ANALISTA
        # Bruno CADETE
DictWriter — escrever com cabeçalho: 
import csv

campos = ['nome', 'nivel', 'ativo']
agentes = [
    {'nome': 'Ana', 'nivel': 'ANALISTA', 'ativo': True},
]

with open('agentes.csv', 'w', newline='', encoding='utf-8') as f:
    escritor = csv.DictWriter(f, fieldnames=campos)
    escritor.writeheader()
    escritor.writerows(agentes)

💡 Prefere DictReader/DictWriter — o código faz sentido sem saberes a posição de cada coluna.

Ficheiros de log — dados que contam a história

Cada linha é um evento — com hora, tipo e mensagem

2025-11-14 20:31:02 INFO  Login bem-sucedido: ana
2025-11-14 20:31:45 ERROR Tentativa de acesso negada: IP 10.0.0.99
2025-11-14 20:32:10 INFO  Agente desligado: ana
2025-11-14 20:35:01 ERROR Tentativa de acesso negada: IP 10.0.0.99
erros = []
with open('simulador.log', 'r', encoding='utf-8') as f:
    for linha in f:
        if 'ERROR' in linha:
            erros.append(linha.strip())

print(f'{len(erros)} erros encontrados')
for e in erros:
    print(e)

🔐 Em cibersegurança, analisar logs é o primeiro passo para detetar intrusos.

Simulador v1.0 — dados que sobrevivem

O Simulador passa a guardar e carregar agentes em CSV

import csv

FICHEIRO_AGENTES = 'agentes.csv'

def carregar_agentes():
    agentes = []
    try:
        with open(FICHEIRO_AGENTES, 'r', encoding='utf-8') as f:
            leitor = csv.DictReader(f)
            for linha in leitor:
                agentes.append(linha)
    except FileNotFoundError:
        pass   # primeira vez — ficheiro ainda não existe
    return agentes

def guardar_agentes(agentes):
    with open(FICHEIRO_AGENTES, 'w', newline='', encoding='utf-8') as f:
        campos = ['nome', 'codename', 'nivel']
        escritor = csv.DictWriter(f, fieldnames=campos)
        escritor.writeheader()
        escritor.writerows(agentes)
Missão v1.0 Os dados já não se perdem entre sessões!

Boas práticas com ficheiros

Pequenos detalhes que evitam problemas grandes

✔ Sempre with open()
Nunca fechas por acidente.
✔ Sempre encoding='utf-8'
Acentos e caracteres especiais funcionam.
✔ newline='' no CSV
Evita linhas em branco duplicadas no Windows.
✔ Caminhos relativos
'agentes.csv' em vez de 'C:\\Users\\...' — portátil entre máquinas.
✔ try/except FileNotFoundError
Para quando o ficheiro ainda não existe.
✔ Nunca guardar passwords em claro
Já sabes que vem aí o hashlib na Aula 9 😉

Demonstração ao vivo

Vamos carregar o Simulador v0.5 e adicionar persistência

  1. Abrir o Simulador v0.5 no PyCharm
  2. Adicionar a função carregar_agentes()
  3. Adicionar a função guardar_agentes()
  4. Chamar carregar_agentes() no início do main()
  5. Chamar guardar_agentes() antes de sair
  6. Fechar e abrir o PyCharm — os dados estão lá!
