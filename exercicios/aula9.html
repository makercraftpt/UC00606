Ficheiro de configuração — dados/aula9/config.ini [simulador]
versao = 2.0
max_agentes = 50
ficheiro_dados = agentes.json

[seguranca]
tentativas_max = 3

O programa deve:

  1. Ler a configuração do config.ini com configparser
  2. Carregar os agentes do ficheiro definido na config (agentes.json)
  3. Apresentar um menu: Listar · Adicionar · Pesquisar · Sair
  4. Pesquisar deve usar um set de codenames — não uma lista
  5. Ao adicionar um agente, verificar se já existe (via set) e se não ultrapassa max_agentes
  6. Ao sair, guardar os agentes em JSON e mostrar o SHA-256 dos dados guardados
  7. Não ultrapassar o número de tentativas inválidas definido em tentativas_max
⚠️ Atenção: o ficheiro de dados é definido na config, não hardcoded no código. Separa configuração de lógica.
